# คู่มือจัดการเนื้อหาผ่าน phpMyAdmin

ตั้งแต่รอบ 13 โพสต์ รูปภาพ PDF แบนเนอร์ประชาสัมพันธ์ คลิป Scoop และสินค้า อยู่ในฐานข้อมูล `e2imedu` ทั้งหมด แก้ใน phpMyAdmin แล้วหน้าเว็บเปลี่ยนทันที ไม่ต้องอัปโหลดไฟล์ผ่าน FTP และไม่ต้องแก้ไฟล์ JSON

> **ปกติให้ใช้หน้าหลังบ้าน** (ดู `templates/README-admin.md`) ทำทุกอย่างในคู่มือนี้ได้โดยไม่ต้องเขียน SQL คู่มือนี้ไว้ใช้เมื่อหลังบ้านเข้าไม่ได้ ต้องแก้หลายแถวพร้อมกัน หรือต้องลบแถวถาวร (หลังบ้านซ่อนโพสต์ได้แต่ไม่ลบ)

> คู่มือนี้ใช้ได้เมื่อตั้ง `'content_source' => 'mysql'` ใน private/database.php แล้วเท่านั้น

## ตารางที่ใช้

| ตาราง | เก็บอะไร |
| --- | --- |
| `posts` | โพสต์ทุกประเภท: `research` งานวิจัย, `innovations` นวัตกรรม, `workshops` เวิร์กช็อป, `media` สื่อและคู่มือ, `news` ข่าว |
| `media` | ไฟล์รูปและ PDF (ชื่อตารางซ้ำกับประเภทโพสต์ "media" แต่เป็นคนละเรื่องกัน) |
| `post_links` | งานที่เกี่ยวข้อง (การ์ดท้ายโพสต์) |
| `home_items` | แบนเนอร์ประชาสัมพันธ์ (`promo`) และคลิป Scoop (`video`) บนหน้าแรก |
| `shop_items` | สินค้าในหน้าร้านค้า |
| `events` | กิจกรรมบนหน้าแรก |
| `v_posts`, `v_media` | มุมมองไว้ดูอย่างเดียว: รายการโพสต์พร้อมชื่อรูปปก และรายการรูปพร้อมขนาด |

ทุกคอลัมน์มีคำอธิบายภาษาไทย เปิดตารางแล้วไปที่แท็บ **Structure** ดูช่อง Comments ได้

## 1. อัปโหลดรูป

1. คลิกตาราง `media` แล้วไปที่แท็บ **Insert**
2. `filename` ใส่ชื่อไฟล์ที่จำง่ายและไม่ซ้ำ เช่น `workshop-pck-2570.webp`
3. `alt_default` ใส่คำอธิบายว่าในรูปมีอะไร สำหรับผู้พิการทางสายตา
4. `data` กด **Browse/Choose file** แล้วเลือกรูป
5. ช่อง `mime`, `width`, `height`, `og_of` ปล่อยว่างได้ ส่วน `sha256` กับ `bytes` ระบบคำนวณเอง
6. กด **Go** แล้วเปิดแท็บ **Browse** ดูเลข `id` ของรูปที่เพิ่ม เลขนี้จะใช้ในขั้นต่อไป

รูปที่ควรใช้:

- ไฟล์ WebP, JPG หรือ PNG ไม่เกิน 1 MB และกว้างไม่เกิน 1920 px (ย่อด้วย squoosh.app ได้)
- รูปปกโพสต์ใช้แนวนอน
- แบนเนอร์ประชาสัมพันธ์ใช้สัดส่วน 2:1 (1920×960) เพราะข้อความอยู่ในตัวรูป

ถ้า phpMyAdmin แจ้งว่าไฟล์ใหญ่เกิน ให้ย่อรูปก่อน (ขนาดสูงสุดขึ้นกับ hosting)

**เปลี่ยนรูป:** แก้แถวเดิม (Edit) แล้วเลือกไฟล์ใหม่ในช่อง `data` ทุกหน้าที่ใช้รูปนั้นจะเปลี่ยนตาม

**ลบรูป:** ลบได้เฉพาะรูปที่ไม่มีโพสต์ใช้อยู่ ถ้ายังมีโพสต์ใช้ ระบบจะไม่ยอมลบ

## 2. เพิ่มโพสต์

วิธีที่ง่ายที่สุดคือคัดลอกโพสต์ที่มีอยู่แล้วมาแก้: เปิดตาราง `posts` > **Browse** > กด **Copy** ที่แถวที่คล้ายกัน แล้วแก้ทีละช่องตามตารางนี้ (ห้ามกรอกช่อง `id` ให้ปล่อยว่าง)

| ช่อง | ใส่อะไร |
| --- | --- |
| `kind` | `research`, `innovations`, `workshops`, `media` หรือ `news` |
| `slug` | ชื่อในลิงก์ เป็นภาษาอังกฤษตัวเล็ก ตัวเลข และ `-` เช่น `smart-farm-kit` ห้ามซ้ำ และเปลี่ยนแล้วลิงก์เดิมจะเสีย |
| `title` | ชื่อเรื่อง |
| `summary` | สรุป 1–2 ประโยค |
| `body` | เนื้อหา ดูรูปแบบด้านล่าง |
| `image_id` | เลข id ของรูปปกในตาราง `media` (ช่อง `image` ปล่อยว่าง) |
| `post_date` | วันที่ปี ค.ศ. เช่น `2026-11-05` เว้นว่างได้ |
| `author` | ผู้จัดทำ เช่น `รศ. ดร.ศศิเทพ ปิติพรเทพิน, ดร.สุกานดา จงเสริมตระกูล และคณะ` |
| `category` | เฉพาะนวัตกรรม: `สะเต็มศึกษา`, `เทคโนโลยีดิจิทัล`, `พัฒนาครู`, `ปฐมวัยบูรณาการ`, `สุขภาวะและพลศึกษา` หรือ `ศึกษาอาชีวะ` (สะกดให้ตรง) |
| `refs` | อ้างอิง เช่น `["ชื่อ. (2569). เรื่อง.", "ชื่อ. (2568). เรื่อง."]` หรือปล่อยว่าง |
| `audience`, `subjects`, `features` | รายการ "เหมาะกับ" "ใช้ได้กับกลุ่มสาระ" "ความสามารถหลัก" เขียนแบบเดียวกับ `refs` |
| `featured` | `1` = แนะนำ |
| `is_public` | `1` = เผยแพร่, `0` = ซ่อน |
| `sort_order` | ลำดับ เลขน้อยขึ้นก่อน ใช้กับหน้าเวิร์กช็อป (เรียงตามลำดับนี้) ส่วนงานวิจัยและนวัตกรรมเรียงตามวันที่ใหม่สุดก่อน ลำดับนี้ใช้เมื่อวันที่เท่ากัน (อยากให้เวิร์กช็อปใหม่อยู่บนสุด ใส่ `-1`) |

### รูปแบบของ `body`

เนื้อหาเขียนเป็นรายการในวงเล็บเหลี่ยม ข้อความแต่ละย่อหน้าอยู่ในเครื่องหมายคำพูด และคั่นด้วยจุลภาค

```json
[
  "ย่อหน้าแรก",
  "ย่อหน้าที่สอง",
  {"media": 31, "alt": "ครูกำลังต่อวงจรเซนเซอร์", "caption": "กิจกรรมช่วงบ่าย"},
  "ย่อหน้าที่สาม"
]
```

- `{"media": 31, ...}` คือรูปกลางเนื้อหา ใช้เลข id จากตาราง `media`
- `alt` ต้องมี เว้นแต่ใส่ `alt_default` ไว้ที่รูปแล้ว
- `caption` ไม่บังคับ
- ถ้าในข้อความมีเครื่องหมาย `"` ให้เขียนเป็น `\"`

ถ้าพิมพ์ผิด เช่น ลืมจุลภาคหรือเครื่องหมายคำพูด phpMyAdmin จะไม่ยอมบันทึก (ขึ้น error `chk_posts_json`) ให้ตรวจรูปแบบที่ jsonlint.com ก่อน แล้วค่อยวางใหม่

### งานที่เกี่ยวข้อง

เพิ่มการ์ด "งานที่เกี่ยวข้อง" ได้ที่ตาราง `post_links` > Insert:

- `from_kind`, `from_slug` = โพสต์ต้นทาง
- `to_kind`, `to_slug` = โพสต์ที่จะลิงก์ไปหา

ลิงก์จะแสดงทั้งสองฝั่งเมื่อต้นทางเป็นเวิร์กช็อป

### PDF ฉบับเต็ม

อัปโหลด PDF เข้าตาราง `media` แบบเดียวกับรูป แล้วนำเลข id ไปใส่ในช่อง `download_id` ของโพสต์ ส่วน `download_label` ใช้กำหนดข้อความบนปุ่ม (เว้นว่างได้)

## 3. ซ่อนโพสต์

ตั้ง `is_public` เป็น `0` โพสต์จะหายจากทุกหน้า และลิงก์ของโพสต์จะขึ้น "ไม่พบรายการ" รูปที่โพสต์นี้ใช้เพียงโพสต์เดียวจะถูกปิดด้วย

ให้ใช้วิธีนี้แทนการลบ เพราะเปิดกลับได้ด้วยการตั้งเป็น `1`

## 4. ประชาสัมพันธ์และ Scoop บนหน้าแรก

ตาราง `home_items`:

- **แบนเนอร์:** `type` = `promo` แล้วกรอก `title` (คำอธิบายรูป), `image_id`, `url` (ลิงก์เมื่อคลิก ใส่ `#` ถ้าไม่ต้องลิงก์) และ `item_date`
- **คลิป:** `type` = `video` แล้วกรอก `title` และ `youtube` (ลิงก์เต็มของคลิป) ช่อง `image_id` เว้นว่างได้ ระบบจะใช้ภาพจาก YouTube
- **ลำดับ:** ใช้ `sort_order` (น้อยขึ้นก่อน)
- **ซ่อน:** ตั้ง `is_public` เป็น `0`

รายการที่ขึ้นต้นด้วย `[ตัวอย่าง]` เป็นข้อมูลตัวอย่าง ให้ซ่อนหรือแก้เป็นของจริง

## 5. ร้านค้า

ตาราง `shop_items`:

- `slug` และ `title`
- `price`: ตัวเลขล้วน เช่น `1200` จะแสดงเป็น ฿1,200 หรือใส่ข้อความ เช่น `สอบถามราคา`
- `order_url`: ลิงก์สั่งซื้อ เว้นว่างไว้จะพาไปหน้าติดต่อเรา
- `image_id` และ `is_public`

## 6. การตัดคำภาษาไทย

ย่อหน้าที่เพิ่มหรือแก้ใน phpMyAdmin แสดงผลได้ทันที แต่เบราว์เซอร์อาจตัดบรรทัดกลางคำบ้าง ถ้าอยากให้ตัดคำสวยขึ้น ให้ส่งงานนี้ให้ผู้ดูแลเว็บ:

1. ตาราง `posts` > **Export** > Format: **JSON** > Go
2. ส่งไฟล์ให้ผู้ดูแลเว็บ ผู้ดูแลจะรัน `python3 tools/segment_thai.py --phpmyadmin-json posts.json`
3. นำไฟล์ `database/thai-breaks.sql` ที่ได้ไป Import

## 7. สำรองข้อมูล (สำคัญมาก)

มหาวิทยาลัยไม่สำรองข้อมูลให้ และตอนนี้รูปทั้งหมดอยู่ในฐานข้อมูล ถ้าฐานข้อมูลเสียจะเสียทั้งเนื้อหาและรูป จึงควรสำรองทุกครั้งที่แก้เนื้อหาเสร็จ หรืออย่างน้อยสัปดาห์ละครั้ง:

1. คลิก `e2imedu` > แท็บ **Export**
2. เลือก **Custom**: เลือกทุกตาราง, Format **SQL**, Compression **gzipped** และให้ติ๊ก "Dump binary columns in hexadecimal notation" ไว้ (ติ๊กอยู่แล้วโดยปกติ)
3. กด Go แล้วเก็บไฟล์ไว้นอก server เช่น Google Drive ของหน่วยงาน โดยตั้งชื่อตามวันที่

## ข้อห้าม

- ห้าม Import ไฟล์ `database/content-schema.sql` ซ้ำ เพราะไฟล์นี้จะลบโพสต์ทั้งหมดแล้วสร้างใหม่จากไฟล์เก่า
- ห้ามแก้ช่อง `sha256`, `bytes` และ `og_of` ในตาราง `media`
- ห้ามลบแถวใน `posts` ให้ใช้ `is_public = 0` แทน
- ถ้าหน้าเว็บขึ้น "ปิดปรับปรุงชั่วคราว" แปลว่าเว็บต่อฐานข้อมูลไม่ได้ ให้แจ้งผู้ดูแลเว็บ ข้อมูลไม่ได้หายไปไหน
