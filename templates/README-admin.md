# คู่มือหลังบ้าน

เปิด `https://โดเมนของเว็บ/admin/` แล้วล็อกอินด้วยอีเมลและรหัสผ่าน (ไม่มีปุ่มบนเว็บไปหน้านี้) ทุกอย่างที่บันทึกจะขึ้นบนเว็บทันที

## 1. สร้างโพสต์ใหม่
กดปุ่มสีน้ำเงิน **+ สร้างโพสต์ใหม่** ที่หน้าแรกของหลังบ้าน

![หน้ารายการโพสต์](admin-guide/1-list.png)

## 2. กรอกแล้วกดเผยแพร่
เลือกประเภท พิมพ์หัวข้อ เลือกรูปปก เขียนเนื้อหาในช่องใหญ่ (เว้นหนึ่งบรรทัดว่าง = ขึ้นย่อหน้าใหม่) แล้วกด **เผยแพร่** ถ้ายังไม่พร้อมกด **เก็บเป็นร่าง** (ยังไม่แสดงบนเว็บ) หรือ **ดูตัวอย่าง** ก่อนได้

![สร้างโพสต์](admin-guide/2-new.png)

ใส่รูปในเนื้อหา: เลือกรูปที่ "รูปในเนื้อหา" จะได้ชื่อ `[รูป 1]` กดปุ่ม "แทรกตรงเคอร์เซอร์" หรือพิมพ์ `[รูป 1]` เองในบรรทัดที่ต้องการ

## 3. เขียนเนื้อหา (หัวข้อ รูป ตาราง) และตั้งค่าที่แถบข้าง
หน้าเขียนโพสต์เป็นแผงเดียวแบบ WordPress: ช่องบนสุดคือหัวข้อโพสต์ (H1) ตามด้วยบล็อกเนื้อหา ส่วนข้อมูลเสริมอยู่ที่แถบด้านขวา (บนมือถืออยู่ใต้เนื้อหา)
- **ย่อหน้า:** พิมพ์ได้เลย กด Enter เพื่อขึ้นย่อหน้าใหม่ วางข้อความหลายบรรทัด ระบบแยกเป็นย่อหน้าให้
- **หัวข้อ:** กดปุ่ม + H2 / + H3 / + H4 หรือพิมพ์ `## ` นำหน้าย่อหน้า (`# ` = H2, `## ` = H3, `### ` = H4) หรือกดปุ่ม H2 H3 H4 บนบล็อกเดิมเพื่อเปลี่ยนระดับ
- **รูป:** กด + รูปภาพ (เลือกได้หลายไฟล์พร้อมกัน ไม่จำกัดจำนวน) หรือลากไฟล์มาวาง หรือวางรูปที่คัดลอกไว้ (Ctrl+V) ใส่คำอธิบายรูปใต้รูปทุกรูป (ถ้าเว้นว่าง รูปจะไม่แสดงบนเว็บ)
- **ตาราง:** กด + ตาราง แล้วพิมพ์ในช่อง หรือก็อปตารางจาก Excel / Google Sheets / Word มาวาง หรือลากไฟล์ .csv มาวาง (ไม่เกิน 100 แถว 12 คอลัมน์) ปุ่ม + แถว / + คอลัมน์ เพิ่มช่อง
- เมื่อคลิกบล็อกจะมีแถบเครื่องมือเล็กๆ: เลื่อนขึ้น ▲ ลง ▼ และลบ (ลบแล้วกด “เลิกทำ” ได้) บล็อกใหม่แทรกต่อจากบล็อกที่เลือกอยู่
- ที่แถบข้าง: เผยแพร่ / บันทึกร่าง / ดูตัวอย่าง, ประเภทโพสต์, หมวด, รูปปก, สรุปสั้น, ผู้เขียนและวันที่ และ “ตัวเลือกเพิ่มเติม”
- ถ้าปิดหน้าไปก่อนบันทึก เบราว์เซอร์นี้จะเก็บสิ่งที่พิมพ์ไว้ให้ เปิดโพสต์เดิมอีกครั้งจะมีปุ่ม “กู้คืน”
- **งานวิจัย ↔ นวัตกรรม:** เปลี่ยนที่ “ประเภทโพสต์” แล้วกดบันทึก ลิงก์เก่าพาไปที่ลิงก์ใหม่ให้เอง งานวิจัยใช้หมวดชุดเดียวกับนวัตกรรม (6 หมวด) แต่ไม่แสดงในเมนูและหน้าหมวดของนวัตกรรม
- ถ้าเบราว์เซอร์ปิด JavaScript หน้านี้จะกลับเป็นช่องข้อความแบบเดิม (เว้นบรรทัดว่าง = ย่อหน้า, `# ` `## ` `### ` = หัวข้อ, `[รูป 1]` `[ตาราง 1]` = ตำแหน่งรูปและตาราง)

![หน้าเขียนโพสต์](admin-guide/5-content.png)

## 4. แก้ไขหรือซ่อนโพสต์
กดหัวข้อโพสต์ในรายการ แก้แล้วกด **บันทึกการแก้ไข** ถ้าไม่ต้องการให้แสดงกด **ซ่อนจากเว็บ** (ไม่ลบ เลิกทำได้ทันที) ผิดพลาดแล้วอยากกลับไป: เปิด "ดูฉบับก่อนหน้า" ท้ายหน้า

![แก้ไขโพสต์](admin-guide/3-edit.png)

## 5. เรื่องอื่นๆ
ท้ายหน้าแรกมีลิงก์ **จัดการอื่นๆ**: คลังรูป, แบนเนอร์หน้าแรก (ประชาสัมพันธ์และวิดีโอ ใช้ปุ่ม ขึ้น/ลง เรียงลำดับ), ร้านค้า และสำหรับผู้ดูแลระบบ: ตั้งค่าเว็บ, ผู้ใช้, สำรองข้อมูล (ควรดาวน์โหลดไฟล์สำรองเป็นประจำ)

![แบนเนอร์หน้าแรก](admin-guide/4-more.png)

## ติดตั้งครั้งแรก (ทำครั้งเดียว สำหรับผู้ดูแลเว็บ)
1. phpMyAdmin → `e2imedu` → Import → `database/updates/2026-10-27-04-admin.sql` (รันซ้ำได้)
   และ `database/updates/2026-10-28-01-views.sql` (ตัวนับจำนวนการเข้าชม; ผู้ใช้ DB ของเว็บต้องมีสิทธิ์เขียน 3 ตารางนั้น ดูท้ายไฟล์ ถ้าไม่พร้อม หน้าแรกของหลังบ้านจะขึ้นคำเตือนสีแดง)
2. ใน `private/database.php` ใส่ `'setup_token' => 'ข้อความสุ่ม 24 ตัวขึ้นไป'` (และ `admin_user`/`admin_pass` ถ้าสร้างผู้ใช้ DB ตัวที่สอง ดูท้ายไฟล์ 04)
3. อัปโหลดโฟลเดอร์ `admin`, `includes/admin`, `assets/css`, `assets/js` และไฟล์ที่แก้ แล้วลบ `admin/log.php` บนเซิร์ฟเวอร์ (ถ้ามี)
4. เปิด `/admin/setup.php` สร้างผู้ดูแลระบบคนแรก แล้ว **ลบ setup_token ออก** ใช้รหัสผ่านยาว (12 ตัวขึ้นไป) ไม่ซ้ำกับที่อื่น
