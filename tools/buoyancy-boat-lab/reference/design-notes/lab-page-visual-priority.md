Race submission on the boat-building page is an optional continuation, not the main call to action. Keep it accessible without a large high-contrast block dominating the lab.

**Why:** The user objected to the conspicuous race-submission section below the builder; the page's main purpose is to build and investigate the boat.

**How to apply:** When changing the lab layout, prioritize builder, simulation, measurements, and experiment notes. Present the race form as a compact, low-emphasis secondary section while preserving a clear path for students who arrive with an invitation code.
